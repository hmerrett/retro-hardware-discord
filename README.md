# Retro Hardware

Resource lists for retro hardware projects.

## Lists

- [Pico-powered retro hardware projects](pico.md): projects built on the Raspberry Pi Pico (RP2040 / RP2350)

## Adding a project

Add a row to the table in the relevant list. Fill in the `Link` and `Notes` columns where known, for example:

```markdown
| PicoGUS | [GitHub](https://github.com/polpo/picogus) | ISA sound card emulator for PCs |
```
